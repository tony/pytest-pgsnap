# pytest integration

pgsnap's snapshot strategies are consumed from pytest through the cache
markers on the {ref}`pgsnap` module, which is in turn compatible with
{mod}`doctest`.

Doctest collection from `.rst` and `.md` sources is provided by
[gp-libs](https://gp-libs.git-pull.com), not by this package.
